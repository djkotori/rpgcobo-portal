# rpgcobo-portal

![Logo Image](rpgcobo-logo.png)

RPG-Cobo の **プロジェクト管理アプリ（ポータルアプリ）** を管理するリポジトリです。  
プロジェクトの作成・管理・起動をまとめて行えるランチャーとして機能します。

通常の利用では、このポータルアプリを通して RPG-Cobo を起動することを推奨しています。

---

## 🚀 RPG-Cobo ポータルアプリとは？

RPG制作を始める際の **入口となるアプリ** です。以下の機能を持っています。

- RPG-Cobo のプロジェクトを一覧管理
- 新規プロジェクトの作成、インポート
- ツールのバージョン管理
- バックアップとレストア
- 将来的にはテンプレート管理やプラグイン管理にも対応予定

## 🛠️ 開発者向け：リポジトリから直接起動する

ポータルアプリ自体を改造したい場合や、HEAD の状態で動作を確認したい場合はこのリポジトリをクローンして直接起動できます。

### 1. リポジトリをクローン
```bash
git clone https://github.com/djkotori/rpgcobo-portal
cd rpgcobo-portal
```

### 2. 実行ファイルを起動
```
rpgcobo-portal.exe
```

※ 通常の利用ではインストーラー版の使用を推奨しています。
