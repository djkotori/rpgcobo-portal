# rpgcobo-portal

![Logo Image](header.jpg)

[⇒ Japanese](README.ja.md)

This is a repository that manages RPG-Cobo's **project management app (portal app)**.  
It functions as a launcher that allows you to create, manage, and launch projects all at once.

For normal use, we recommend starting RPG-Cobo through this portal app.

---

## 🚀 What is the RPG-Cobo portal app?

This is an **entrance app** for starting RPG production. It has the following functions.

- List management of RPG-Cobo projects
- Creating and importing new projects
- Tool version control
- Backup and restore
- In the future, we plan to support template management and plugin management.


---

## 📥 Download the installer (recommended)

You can download the latest stable version of **Portal App Installer** from the following page:

```
👉 https://rpg-cobo.com/download （For Windows）
```

After installation, you can use RPG-Cobo by launching the app.

---

## 🛠️ For developers: launch directly from the repository

If you want to modify the portal app itself or check the operation in the HEAD state, you can clone this repository and launch it directly.

### 1. Clone the repository
```bash
git clone https://github.com/djkotori/rpgcobo-portal
cd rpgcobo-portal
```

### 2. Launch the executable file
```
rpgcobo-portal.exe
```

*For normal use, we recommend using the installer version.
